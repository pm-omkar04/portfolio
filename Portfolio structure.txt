# Case Study 03 — Stock Alerts

### Turning passive users into proactive investors

**Problem**

Users needed a way to monitor stock prices without repeatedly checking the market.

### Solution

Designed **Stock Alerts**, allowing users to configure:

**Stock → Exchange → Alert Type → Target → Notification**

Users can create alerts based on:

* Price
* Percentage movement

Once the condition is met, the user receives a push notification.

### Product thinking

The feature creates a simple loop:

**Set Alert → Leave App → Market Moves → Notification → Return to App**

### Illustrative outcome

> **52% increase in repeat engagement among alert users**
